# إعادة تصميم قائمة التكاملات (الموصلات)

هدف واحد: شيت واحد نظيف بنفس لغة تصميم الشات (خلفية صلبة، بدون حواف أو ظلال، RTL) وبثلاث شاشات مترابطة زي المراجع.

## البنية (3 مستويات)

```text
[1] الشيت الرئيسي: الموصلات
    ├── هيدر: X  |  "الموصلات"  |  +
    ├── بحث: "البحث عن الموصلات"
    ├── تبويبات: تطبيقات | API مخصص | MCP مخصص
    ├── قسم "المتصل" (كروت مجمّعة + سويتش/سهم)
    └── قسم "الكل" (كارت لكل تطبيق: أيقونة + اسم + وصف سطرين + حالة)
[2] شاشة التفاصيل: أيقونة كبيرة + اسم + وصف + جدول تفاصيل + زر "اتصال" ثابت أسفل
[3] الحالة الفارغة: أيقونة + نص + زر "الإنشاء عبر الدردشة" (لتبويب MCP/API)
```

## قواعد التصميم الموحّدة

- خلفية الشيت `#1c1c1c`، الكروت `#262627`، النشط `#1f1f20` — كلها صلبة بدون blur/شفافية.
- استدارة: الشيت 26px، الكروت 18px، الصفوف 14px، الشيبس pill.
- بدون `border` وبدون `box-shadow` في أي عنصر.
- الأيقونات: مربع 44px استدارة 12px بخلفية موحّدة، مع fallback حرف أول.
- التبويب النشط: خلفية بيضاء ونص أسود؛ غير النشط شفاف بنص رمادي.
- الحالة: متصل = سويتش/علامة صح بلون النعناع؛ غير متصل = نص "اتصال" رمادي على اليسار (مش زرار ملوّن لكل صف).
- المسافات: padding أفقي 16px، فاصل بين الأقسام 20px، ارتفاع الصف ≥ 64px.

## السلوك

- فتح: spring من أسفل، سحب لأسفل من أي مكان (لما `scrollTop<=0`) للإغلاق بأنيميشن انزلاق + fade — نفس فيزياء قائمة زر +.
- البحث يفلتر فوريًا داخل التبويب الحالي.
- الضغط على كارت تطبيق → شاشة التفاصيل (انتقال أفقي slide داخل نفس الشيت، مع رجوع).
- زر "اتصال" في التفاصيل يشغّل نفس منطق `startIntegrationConnection` الحالي مع حالة تحميل داخل الزر.
- التطبيقات المتصلة تظهر أعلى القائمة في مجموعة "المتصل" مع سويتش تفعيل/فصل سريع.
- تبويبات API/MCP: لو مفيش عناصر → حالة فارغة + "الإنشاء عبر الدردشة".
